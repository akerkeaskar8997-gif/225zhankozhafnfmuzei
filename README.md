# Жанқожа Нұрмұхаммедұлы атындағы цифрлық мұражай

Қызылорда облысы, Қазалы ауданы, Кәукей ауылы, №225 орта мектеп.

Мектеп мұражайының цифрлық кеңістігі: 6 цифрлық бағыт — цифрлық музеология, цифрлық гуманитаристика, 3D модельдеу және цифрлық реконструкция, геоақпараттық технологиялар, цифрлық сторителлинг, музей экспонаттарын ғылыми зерттеу.

*«Тарихты тану – тәуелсіздікті қадірлеу, мұраны сақтау – болашаққа аманат».*
